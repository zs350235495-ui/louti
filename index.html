       └─► 4. 国内目标 ──► 回源 iKuai 主路由 NAT ──► 国内高速互联
准则 1: 故障解耦与旁路容灾 旁路网关升级重启或意外宕机，仅影响外网分流；主路由依旧维系全屋千兆内网、NAS 备份与国内网络不中断。
准则 2: 关闭双向 NAT 回环 旁路由必须配置静态 ARP 或关闭 masquerade 伪装，避免内网 IP 全部被重写为旁路网关 IP，造成流控日志失真。
准则 3: MTU 最佳对齐 跨境专线封装头通常占用 28~40 字节，建议将旁路 TUN 虚拟网卡 MTU 设置为 1420~1460，杜绝分片造成的晚高峰丢包。

01

假专线精准识别

警惕月付几元的伪专线。许多是用廉价公网隧道混装，一旦晚高峰公网海缆发生拥塞，丢包瞬间飙升至 30% 以上。

02

DNS 双向防污染

杜绝直接使用明文 UDP 53 解析境外域名。必须通过 TLS 加密隧道与 MosDNS 剥离 ECS，确保应答地址零投毒污染。

03

UDP 拥塞与阻断应对

针对跨洋链路上针对 UDP/QUIC 的 QOS 限制，建议客户端配置自动回退机制或开启多路复用 Multiplex 保障连接。

04

原生 IP 与风控检测

节点落地选用原生商宽或住宅 ASN。被标记为 DataCenter 的广播机房 IP 极易触发 OpenAI 及金融终端的风控封禁。

OpenWrt 旁路网关防火墙关键指令

NFTables / 防双重 NAT

旁路由常见“国内网站能上但外网打不开”或“设备打不开网页但能 ping 通”，绝大多数因防火墙伪装开启导致回环或 SYN 丢包： 

# 1. 禁用 lan 口伪装 Masquerading (保留源 IP)
uci set firewall.@zone[0].masq='0'
uci commit firewall && /etc/init.d/firewall restart

# 2. 规避 TCP MSS 钳制 (防止大包在隧道内被无声丢弃)
iptables -t mangle -A POSTROUTING -p tcp --tcp-flags SYN,RST SYN -j TCPMSS --clamp-mss-to-pmtu
提示: 主路由需在 DHCP Option 3 填入旁路由 IP，Option 6 填入旁路由 DNS

MosDNS 分层防投毒逻辑 Pipeline

DNS Pipeline Spec

构建三级防御体系：本地优先缓存 ➔ 国内权威直连 ➔ 境外严格剔除 ECS 并封装 DoT： 

pipeline:
  - _lazy_cache                  # 1. 内存极速热点缓存
  - matches: qname $china_domain  # 2. 国内白名单域名命中
    exec:
      - forward_local_dns        # 转发 223.5.5.5 / 119.29.29.29
      - _return
  - exec:
      - _drop_ecs                # 3. 剥离客户端 IP 定位信息防画像
      - forward_remote_dot       # 4. 加密隧道转发 1.1.1.1 (DoT/DoH)
防御效果: 100% 拦截运营商旁路伪造的虚假 127.0.0.1 投毒 IP

现代化客户端最佳分流策略推荐 (Clash Verge / Sing-box / Surge)

01. 基础分流策略 (Clash/Mihomo)

针对 `cn` 域名及国内 IP 集合启用 Direct 直连，杜绝国内网关、应用被误代理，同时降低节点不必要的带宽消耗。

02. 专线节点策略组 (ProxyGroup)

将 IPLC/IEPL 优质节点设为专用组，配置高阈值 URL-Test 自动优选（容忍差值设置为 20ms 以内），规避频繁跳点。

03. AI与原生流媒体分流策略

为 OpenAI / Anthropic 等单独配置分流规则组，固定指向原生住宅或纯净 IP 落地节点，避免频遭 Cloudflare 拦截。
